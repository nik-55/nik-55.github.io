# nik-55.github.io

My personal site, live at [nik-55.github.io](https://nik-55.github.io/).

A single static `index.html`. Tailwind, Font Awesome and Google Fonts all load from CDN, so there is no build step and no dependencies to install.

## Local preview

Open `index.html` in a browser, or serve the folder:

```
python3 -m http.server 8000
```

## Files

| Path | Purpose |
| --- | --- |
| `index.html` | The whole site |
| `images/preview.png` | Open Graph and Twitter card image |
| `Nikhil_Mahajan_CV.pdf` | CV linked from the page |
| `favicon.ico` | Favicon |
| `google72eea879f1766324.html` | Google Search Console verification |

Deploys from `master` through GitHub Pages.
